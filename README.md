# WISE / FRAME — публичные сайты

Безопасная статическая публикация двух проектов:

- WISE / FRAME — портфолио, калькулятор CTR/CVR, архив, диагностика и preview Telegram Mini App;
- WISE / REACH — кабинет поиска клиентов, контент-план, сценарии и черновики коммуникации.

## Границы GitHub Pages

GitHub Pages публикует только статический интерфейс. Здесь отключены Telegram `initData`, серверная передача заявок, закрытая панель, база данных, платежи Stars и выдача платного доступа. Диагностический маршрут рассчитывается в браузере и не отправляет введённые данные.

## Локальная проверка

```powershell
python -m http.server 4205 --directory C:\Users\GIGA\Desktop\WISE_FRAME_SITES_PUBLIC
```

Открыть `http://127.0.0.1:4205/` и `http://127.0.0.1:4205/reach/`.

Совместимый адрес для старых Telegram-кнопок: `/miniapp`. Он перенаправляет на hash-маршрут `/#/miniapp` и сохраняет параметр экрана.
